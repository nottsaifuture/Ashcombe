# Ashcombe I — Sherbourne

Interactive 3D home presentation and walkthrough.

https://nottsaifuture.github.io/Ashcombe/

Rotate and zoom to explore, select floors and rooms, or choose Walkthrough. Use keyboard movement or enable Touch controls, and open doors as you approach.

Independent demonstration · not affiliated with or endorsed by Spitfire Homes. Dimensions and finishes are illustrative where not confirmed by the supplied plans.

This repository contains the built viewer only. Editable project files remain local.
